================================================================================
SUMMARY STATEMENT
================================================================================

All datasets underwent standardized column name harmonization to enable 
comparative analysis. Only columns including information on yield, coordinates, 
crop species, harvest year, distance to tree strip, treatment applied on the field,
site name, plot and the environmental variables of the field were included. 
Original source columns (ranging from crop-specific abbreviations like "sm_dm", 
"or_dm" to coordinate labels like "x", "y") were systematically mapped to a 
unified naming scheme: temporal variables standardized to "year," spatial 
variables to "distance_to_tree_strip" (meters), and crop production to 
"yield" and "yield_straw" (units recorded separately per dataset: 
g/m², t/ha, or kg/m²). Distance values extracted from plot identifiers via 
regular expression pattern matching or continuous measurement values binned into 
discrete 1, 4, 7, 12, 18, and 24 m categories for cross-dataset comparability. 
Rows lacking crop yield data (indicating wood-only harvest events) were excluded, 
as they provide no information on the primary response variable. Area-weighted 
aggregate measurements (AFcrop entries) were excluded to retain only direct field 
observations.


================================================================================
BROAD PATTERN: SYSTEMATIC STANDARDIZATION
================================================================================

THREE CORE COLUMN CATEGORIES STANDARDIZED ACROSS ALL DATASETS:

1. TEMPORAL VARIABLE
   Original names: harvest_year, embedded in date fields
   Standard name: year
   
2. SPATIAL DISTANCE VARIABLE
   Original formats: Embedded in plot ID (regex extraction), separate column, 
                     continuous values
   Standard name: distance_to_tree_strip (units: meters)
   Special handling: Koch25 binned continuous values
   
3. CROP PRODUCTION METRICS
   Original names: Crop-specific abbreviations (sm_dm, or_dm, sb_dm, 
                   corn_dry_weight_t_per_ha, grain_kg_m2, grass_dm, 
                   yield_wweight, etc.)
   
   Standard names:
   - yield = primary production metric (grain, corn, or grass dry mass)
   - yield_straw = secondary biomass (straw, chaff, or total plant dry matter)
   - yield_total = when both components recorded separately


CONSISTENT EXCLUSION RULE ACROSS ALL DATASETS:

Rows excluded when yield is NA (Lines 104, 150, 183, 213, 387, 422):
- Rationale: Agroforestry trials sometimes harvested only wood/tree biomass 
             with no crop yield
- Impact: These rows had no data on the primary response variable (crop 
         production) and would not contribute to distance-effect models

Special exclusions:
- AFcrop entries (Lines 307, 336): Weighted aggregates, not primary observations
- Distance extraction failures (e.g., control plots): Rows with NA in 
  distance_to_tree_strip retained but flagged (represent unlocated control sites)
